# data/

Raw and processed data live here but are **not committed** to git (see
`.gitignore`) — data should be either regenerated by a script/notebook or
downloaded from its source, not stored in version control.

Suggested layout:

```
data/
├── raw/         # untouched, as downloaded/generated — never edited by hand
└── processed/   # cleaned/derived data produced by scripts in scripts/
```

If a dataset must be versioned (e.g. it's small and not reproducible any
other way), document its provenance here and commit it explicitly with
`git add -f`.
