\subsection{Analytical solutions for OLS and Ridge}

\Cref{fig:ols_mse_r2_vs_degree} shows the training and test error of the OLS fit as a function of polynomial degree. The training error decreases monotonically with degree, while the test error flattens out and then rises, the qualitative signature of overfitting: past some complexity the added flexibility is spent on the noise realization rather than on $f$. For this particular split the test MSE is minimized at degree $12$. The left panel reproduces the behavior of fig.~2.11 of \textcite{hastieElementsStatisticalLearning2017}, although less clear.

For $n = 100$ points drawn uniformly from $[-1,1]$, noise level $\sigma = 0.1$, a 80/20 train--test split, and predictors centered and scaled using statistics computed on the training set only.}
    \label{fig:ols_mse_r2_vs_degree}

%\Cref{fig:ols_test_mse_r2_by_n} shows a seemingly counter-intuitive result: the test MSE for $n=50$ and $n=100$ is lower than for $n=500$ and $n=1000$. This does not imply that more training data makes OLS worse. Each dataset size uses a different random train--test split, and the test set grows with $n$ (from 10 points at $n=50$ to 200 at $n=1000$). When the fit is close to $f$, the standard error of an MSE estimate from $m$ test points is approximately $\sigma^2\sqrt{2/m}$, i.e.\ about $0.45\sigma^2$ for $m=10$ versus $0.1\sigma^2$ for $m=200$. The value $0.0067$ obtained at degree 10 for $n=50$ lies below the irreducible error $\sigma^2 = 0.01$, which is only possible because the ten test residuals happened to be small. Test MSE also only measures error where test points lie: the $n=50$ test points span roughly $x \in [-0.88, 0.65]$, so the large boundary oscillations of the high-degree fits (\cref{fig:ols_fits_n50}) are never penalised. At low degrees, test-set composition matters as well: the strongly negative $R^2$ for $n=100$ at degree 1 reflects a test set with low variance, containing few points near the peak at $x=0$. Repeated splits or cross-validation would give a more reliable comparison. Since the true function is known, evaluating each fit against $f(x)$ on a dense grid would remove the split dependence entirely.

\subsection{Bias--variance via resampling}

\Cref{fig:bias_variance_tradeoff_bootstrap} shows the bias--variance decomposition from \cref{eq:bias-variance-decomposition}, with bias estimated as in \cref{eq:measured-bias}, for the OLS estimators. Simple models are dominated by bias, while complex models are dominated by variance; the best-performing degree lies between the two regimes, where both terms are small and the test MSE nearly reaches the irreducible noise floor $\sigma^2$.
