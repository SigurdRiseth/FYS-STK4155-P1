\subsubsection{Tools used}

Below we summarize all AI tools used in the development and writing of this project.

\begin{itemize}
    \item Anthropic's Claude, accessed via \url{https://claude.ai/} and Claude Code, September--October 2026. Models used include Claude Sonnet 4 and Claude Opus 4.
    \item OpenAI's ChatGPT, accessed via \url{https://chatgpt.com/}, September--October 2026.
\end{itemize}
