\section{Methods}
\label{sec:method}

This section presents the models, the error decomposition and the numerical
methods of the study: linear regression by ordinary least squares, Ridge and
Lasso; the bias--variance decomposition; the bootstrap and $k$-fold
cross-validation; and gradient-based optimization, including its
application to Lasso and automatic differentiation. We assume the reader has
familiarity with basic linear algebra and statistics.

\subsection{Linear regression}
\label{subsec:linear-regression}

We are given a dataset with $n$ samples $\mathcal{D} = \{(y_i, x_i)\}_{i=0}^{n-1}$
and assume that the targets $y_i$ are generated by
\begin{equation}\label{eq:data_generating_process}
    \bm{y} = \bm{f} + \bm{\varepsilon}, \qquad
    \bm{\varepsilon} \sim \mathcal{N}(\bm{0}, \sigma^2\bm{I}_n),
\end{equation}
where $\bm{f} = (f(x_0), \dots, f(x_{n-1}))^\top$ collects the values of an
unknown function $f$ and the noise is i.i.d.\ Gaussian with zero mean and variance
$\sigma^2$. A polynomial model of degree $p$ is linear in its parameters: with
the design matrix $\bm{X} \in \mathbb{R}^{n\times p}$ and
the parameter vector $\bm{\theta}\in\mathbb{R}^{p}$, the prediction is
$\tilde{\bm{y}} = \bm{X}\bm{\theta}$~\cite{hjorth-jensen_2026}. The goal of
linear regression is to choose $\hat{\bm{\theta}}$ so that the fitted model
$g(\bm{X}; \hat{\bm{\theta}}) = \bm{X}\hat{\bm{\theta}}$ best approximates the
unknown function $f$ on the data $\mathcal{D}$~\cite{mehta_2019}.

\subsubsection{Singular value decomposition}
Any matrix $\bm{X}$ can be factorized as
$\bm{X} = \bm{U}\bm{\Sigma}\bm{V}^\top$, with $\bm{U}$ and $\bm{V}$ orthogonal and
$\bm{\Sigma}$ rectangular diagonal with the singular values $\sigma_0 \geq \sigma_1 \geq \dots \geq 0$. The ratio $\kappa_2(\bm{X}) =
\sigma_{\max}/\sigma_{\min}$ is the 2-norm condition number of $\bm{X}$~\cite{hjorth-jensen_2026}.
The monomial columns $x^j$ on $[-1,1]$ become nearly parallel as $j$ grows,
so $\kappa_2(\bm{X})$ grows exponentially with the degree; this ill-conditioning
is behind several of our numerical results.

\subsubsection{Ordinary least squares}
Ordinary least squares (OLS) chooses $\bm{\theta}$ to minimize the mean squared
error~\cite{mehta_2019},
\begin{equation}\label{eq:ols_cost}
    C_\text{OLS}(\bm{\theta}) = \frac{1}{n}\left\lVert \bm{y}
    - \bm{X}\bm{\theta} \right\rVert_2^2 .
\end{equation}
The cost is convex, since its Hessian $\bm{H} = \frac{2}{n}\bm{X}^\top\bm{X}$ is
positive semi-definite, so every stationary point is a global minimizer. Setting
the gradient $\nabla_{\bm{\theta}} C_\text{OLS} = \frac{2}{n}\bm{X}^\top
(\bm{X}\bm{\theta} - \bm{y})$ to zero gives the normal equations; if
$\bm{X}$ has full column rank, the normal equations have the unique solution
\begin{equation}\label{eq:ols-theta-hat}
    \hat{\bm{\theta}}_\text{OLS} = (\bm{X}^\top \bm{X})^{-1} \bm{X}^\top \bm{y}.
\end{equation}
If $\bm{X}$ is rank-deficient, $\bm{X}^\top\bm{X}$ is singular and the OLS
minimizer is not unique~\cite{mehta_2019}. In this case, the Moore--Penrose pseudoinverse gives
the minimum-norm OLS solution,
\begin{equation}
    \hat{\bm{\theta}}_\text{OLS}
    = \bm{X}^{+}\bm{y}
    = \bm{V\Sigma}^{+}\bm{U}^\top,
\end{equation}
where $\bm{X}^{+}$ denotes the Moore--Penrose pseudoinverse~\cite{goodfellow_2016}.
We compute OLS this way as forming
$\bm{X}^\top\bm{X}$ squares the condition number, which for our design matrices
can exhaust double precision at moderate degree~\cite{hjorth-jensen_2026}.

\subsubsection{Ridge regression}
Ridge regression~\cite{hoerl_1970} adds the $\ell_2$-norm of the parameter vector
to the as a penalty to the cost function,
\begin{equation}\label{eq:ridge_cost}
    C_\text{Ridge}(\bm{\theta}) = \frac{1}{n}\left\lVert \bm{y}
    - \bm{X}\bm{\theta} \right\rVert_2^2 + \lambda \lVert \bm{\theta} \rVert_2^2,
    \qquad \lambda \geq 0,
\end{equation}
where the penalty is added to the same $1/n$-normalized cost used throughout;
this is the convention of our code, and it fixes the meaning of $\lambda$ in
all results. This yields the minimizer
\begin{equation}\label{eq:ridge-theta-hat}
    \hat{\bm{\theta}}_{\text{Ridge}}(\lambda) = \left(\bm{X}^\top \bm{X}
    + n\lambda \bm{I}\right)^{-1} \bm{X}^\top \bm{y}.
\end{equation}
For $\lambda > 0$ the Hessian $\frac{2}{n}\bm{X}^\top\bm{X} + 2\lambda\bm{I}$
is positive definite, so the cost is strictly convex and the minimizer unique
for any $\bm{X}$, full rank or not~\cite{hjorth-jensen_2026}. In terms of the SVD, the Ridge prediction is
\begin{equation}
    \tilde{\bm{y}}_{\text{Ridge}} = \sum_{j} d_j\, \bm{u}_j \bm{u}_j^\top \bm{y},
    \qquad
    d_j = \frac{\sigma_j^2}{\sigma_j^2 + n\lambda},
    \label{eq:ridge_scaling}
\end{equation}
with $d_j\in[0,1)$ for $\lambda>0$, whereas OLS has $d_j = 1$ for every $\sigma_j > 0$.
Directions with $\sigma_j^2 \ll n\lambda$ are suppressed, directions with
$\sigma_j^2 \gg n\lambda$ are kept as in OLS. Ridge therefore suppresses precisely
the directions associated with small singular values, which make the OLS solution
sensitive to noise~\cite{hjorth-jensen_2026}.

\subsubsection{Lasso regression}
Lasso~\cite{tibshirani_1996} applies an $\ell_1$ penalty,
\begin{equation}\label{eq:lasso-theta-hat}
    C_\text{Lasso}(\bm{\theta}) = \underbrace{\frac{1}{n}\left\lVert \bm{y}
    - \bm{X}\bm{\theta} \right\rVert_2^2}_{g(\bm{\theta})}
    + \lambda \lVert \bm{\theta} \rVert_1 .
\end{equation}
The cost is convex but not differentiable where a coefficient is zero, and it
has no closed-form minimizer~\cite{mehta_2019}. Writing $\bm{r} =
\bm{y}-\bm{X}\hat{\bm{\theta}}$ for the residual and $\bm{x}_j$ for column $j$
of $\bm{X}$, the minimizer satisfies
\begin{equation}
    \frac{2}{n}\bm{x}_j^\top\bm{r} = \lambda\,\operatorname{sgn}(\hat\theta_j)
    \quad \text{if } \hat\theta_j \neq 0, \quad
    \left|\frac{2}{n}\bm{x}_j^\top\bm{r}\right| \leq \lambda
    \ \text{if } \hat\theta_j = 0.
    \label{eq:lasso-optimality}
\end{equation}
A coefficient therefore stays exactly zero as long as its column's
correlation with the residual is too weak to outweigh the penalty $\lambda$;
it only enters the model once that correlation exceeds $\lambda$. Ridge's
penalty is smooth at zero, so it has no such dead zone: any nonzero
correlation pulls the coefficient away from zero, just scaled down. This is
why Lasso performs variable selection while Ridge only
shrinks~\cite[Prop.~3.7]{hjorth-jensen_2026}.

\subsubsection{Error measures}
We evaluate a prediction $\tilde{\bm{y}}$ of targets $\bm{y}$ by
\begin{equation}
    \mathrm{MSE} = \frac{1}{n}\sum_{i}(y_i-\tilde{y}_i)^2, \quad
    R^2 = 1 - \frac{\sum_i (y_i - \tilde{y}_i)^2}{\sum_i (y_i - \bar{y})^2},
\end{equation}
with $\bar{y}$ the mean of $\bm{y}$. An unbiased model with no variance reaches
$\mathrm{MSE} = \sigma^2$ in expectation; $R^2$ compares against predicting
$\bar{y}$ and is negative for a model that does worse than that constant~\cite{hjorth-jensen_2026}.

\subsection{Bias--variance decomposition}
\label{subsec:bias-variance}

We decompose the expected squared error $\mathbb{E}[(\bm{y}-\tilde{\bm{y}})^2]$,
the quantity MSE estimates, into bias, variance, and irreducible noise. The
prediction $\tilde{\bm{y}}$ at a fixed set of test inputs is a random
quantity, because the parameters are fitted on a training set that is itself
random. Below, $\mathbb{E}$ is taken jointly over the draw of the training set
(in the bootstrap: over the resampled training sets) and over the noise
$\bm{\varepsilon}$ on the test targets, which is independent of the training set
\cite{hjorth-jensen_2026}. Squares of vectors are
elementwise and averaged over the test points.

Writing $\bm{y}=\bm{f}+\bm{\varepsilon}$ and adding and subtracting
$\mathbb{E}[\tilde{\bm{y}}]$,
\begin{equation}
    \mathbb{E}\!\left[(\bm{y}-\tilde{\bm{y}})^2\right]
    =\mathbb{E}\!\left[\big(
        \underbrace{\bm{f}-\mathbb{E}[\tilde{\bm{y}}]}_{a}
        +\underbrace{\mathbb{E}[\tilde{\bm{y}}]-\tilde{\bm{y}}}_{b}
        +\underbrace{\bm{\varepsilon}}_{c}
    \big)^2\right].
\end{equation}
The cross terms vanish: $a$ is deterministic and $\mathbb{E}[b]=\bm{0}$, so
$\mathbb{E}[ab]=a\,\mathbb{E}[b]=\bm{0}$; $\mathbb{E}[ac]=a\,\mathbb{E}[
\bm{\varepsilon}]=\bm{0}$; and $\bm{\varepsilon}$ is independent of
$\tilde{\bm{y}}$, so $\mathbb{E}[bc]=\mathbb{E}[b]\,\mathbb{E}[\bm{\varepsilon}]
=\bm{0}$. What remains is
\begin{equation}\label{eq:bias-variance-decomposition}
    \mathbb{E}\!\left[(\bm{y}-\tilde{\bm{y}})^2\right]
    =\underbrace{\left(\bm{f}-\mathbb{E}[\tilde{\bm{y}}]\right)^2}_{\mathrm{Bias}^2[\tilde{\bm{y}}]}
    +\underbrace{\mathbb{E}\!\left[\left(\tilde{\bm{y}}-\mathbb{E}[\tilde{\bm{y}}]\right)^2\right]}_{\mathrm{Var}[\tilde{\bm{y}}]}
    +\sigma^2 .
\end{equation}
Averaged over $m$ test points,
\begin{align}
    \mathrm{Bias}^2[\tilde{\bm{y}}]
    &= \frac{1}{m}\sum_i\left(f_i - \mathbb{E}[\tilde{y}_i]\right)^2,
    \label{eq:bias-term}\\
    \mathrm{Var}[\tilde{\bm{y}}]
    &= \frac{1}{m}\sum_i\mathbb{E}\!\left[\left(\tilde{y}_i
    - \mathbb{E}[\tilde{y}_i]\right)^2\right], \label{eq:var-term}
\end{align}
where we estimate $\mathbb{E}[\tilde{y}_i]$ and the inner expectation of
\cref{eq:var-term} by averages over the bootstrap replicates.

The bias measures how far the average prediction is from $f$; it is large when
the model is too rigid to represent $f$. The variance measures how much the
prediction fluctuates when the training set changes; it grows with model
complexity. The noise variance $\sigma^2$ is irreducible and is a floor for the
expected test error~\cite{hjorth-jensen_2026}.

Since $f$ is unknown in practice, the bias is usually measured against the
observed targets $\bm{y}=\bm{f}+\bm{\varepsilon}$. Because $\bm{\varepsilon}$
has mean zero and is independent of $\tilde{\bm{y}}$,
\begin{equation}\label{eq:measured-bias}
    \frac{1}{m}\sum_i\mathbb{E}\!\left[(y_i-\mathbb{E}[\tilde{y}_i])^2\right]
    =\mathrm{Bias}^2[\tilde{\bm{y}}]+\sigma^2,
\end{equation}
so the measured bias absorbs the noise variance, and the measured
$\mathrm{Bias}^2+\mathrm{Var}$ adds up to the full test MSE. Since our data are
synthetic, we report both versions.

\subsection{Resampling methods}
\label{subsec:resampling}

A single train--test split gives one realization of the test error; its
variance can be large when the test set is small. Resampling methods reuse the
available data to estimate the expected test error of a model, and to choose
between models, without collecting new data.

\subsubsection{Bootstrap}
The bootstrap~\cite{efron_1979} approximates the
distribution of the training sets by the empirical distribution of the one
training set we have: we draw $B$ training sets of the same size $n_\text{tr}$
with replacement, refit the model on each, and predict on a fixed test set. The
spread of the $B$ predictions estimates $\mathrm{Var}[\tilde{\bm{y}}]$, their
mean estimates $\mathbb{E}[\tilde{\bm{y}}]$ in \cref{eq:bias-term}, and the
average squared error estimates the test MSE. A bootstrap sample contains on
average only a fraction $1-(1-1/n_\text{tr})^{n_\text{tr}} \approx 1 - e^{-1}
\approx 0.632$ of the distinct training points, so every bootstrap fit is made
from effectively fewer points than the fit on the full training
set~\cite{hastie_2017}.

\subsubsection{\texorpdfstring{$k$}{k}-fold cross-validation}
In $k$-fold cross-validation (CV), the data are split into $k$ disjoint folds of
(almost) equal size. The model is trained $k$ times, each time on $k-1$ folds,
and evaluated on the held-out fold~\cite{geron_2023}. The
CV estimate of the test error is the mean of the $k$ fold errors,
\begin{equation}\label{eq:cv}
    \mathrm{CV}_k = \frac{1}{k}\sum_{i=1}^{k}\mathrm{MSE}\big(
    \bm{y}_{i}, \tilde{\bm{y}}_{i}^{(-i)}\big),
\end{equation}
where $\tilde{\bm{y}}_{i}^{(-i)}$ is the prediction for fold $i$ of the
model trained without it. We select hyperparameters (the degree $p$ and
$\lambda$) by minimizing $\mathrm{CV}_k$ over a
grid~\cite{hjorth-jensen_2026}. Larger $k$ trains on
more data per fit ($1-1/k$ of it), which reduces the pessimistic bias of the
estimate; but the $k$ training sets then overlap more, so the fold errors
become more correlated and the average has higher
variance~\cite{hastie_2017}.

\subsection{Gradient-based optimization}
\label{subsec:gradient-descent}

\subsubsection{Gradient descent}
For a differentiable cost $C(\bm{\theta})$, gradient descent (GD) iterates
\begin{equation}\label{eq:gd_basic}
    \bm{\theta}^{(k+1)} = \bm{\theta}^{(k)} - \gamma
    \nabla_{\bm{\theta}} C\big(\bm{\theta}^{(k)}\big),
\end{equation}
with learning rate $\gamma > 0$. Newton's method,
$\bm{\theta}^{(k+1)} = \bm{\theta}^{(k)} - \bm{H}^{-1}\nabla_{\bm{\theta}}
C(\bm{\theta}^{(k)})$, would solve a quadratic cost in one step, but forming and
inverting the Hessian costs $\mathcal{O}(p^3)$ for $p$ parameters;
GD replaces $\bm{H}^{-1}$ by $\gamma\bm{I}$ and costs one gradient evaluation
per iteration~\cite{hjorth-jensen_2026}.

For the quadratic OLS and Ridge costs the analysis is exact. The error
$\bm{e}^{(k)} = \bm{\theta}^{(k)} - \hat{\bm{\theta}}$ obeys
$\bm{e}^{(k+1)} = (\bm{I} - \gamma\bm{H})\,\bm{e}^{(k)}$, so along the
eigenvector of $\bm{H}$ with eigenvalue $\lambda_i$ the error is multiplied by
$1-\gamma\lambda_i$ in each step. The iteration converges from any starting
point if and only if $|1-\gamma\lambda_i| < 1$ for all $i$ with
$\lambda_i > 0$, that is
\begin{equation}\label{eq:gd_stability}
    0 < \gamma < \frac{2}{\lambda_{\max}(\bm{H})}.
\end{equation}
The slowest direction contracts by $1-\gamma\lambda_{\min}$, so with
$\gamma = 1/\lambda_{\max}$ reaching a relative accuracy $\epsilon$ takes about
$\kappa(\bm{H})\ln(1/\epsilon)$ iterations, where $\kappa(\bm{H}) =
\lambda_{\max}/\lambda_{\min} = \kappa(\bm{X})^2$ for OLS. For Ridge with
centered features, an unpenalized intercept and $\lambda \leq 1$,
$\lambda_{\min} \geq 2\lambda$, so $\kappa(\bm{H}) \leq \lambda_{\max}/(2\lambda)$
however ill-conditioned $\bm{X}$ is.

\subsubsection{Momentum}
Momentum adds a fraction of the previous step,
\begin{equation}\label{eq:gd_momentum}
    \bm{v}^{(k)} = \beta\bm{v}^{(k-1)} + \gamma\nabla_{\bm{\theta}}
    C\big(\bm{\theta}^{(k)}\big), \qquad
    \bm{\theta}^{(k+1)} = \bm{\theta}^{(k)} - \bm{v}^{(k)},
\end{equation}
with $\beta\in[0,1)$ and $\bm{v}^{(0)} = \bm{0}$. Along directions where the
gradient keeps its sign the steps accumulate, while oscillations across a narrow
valley partly cancel; this is what makes momentum effective for ill-conditioned
Hessians~\cite{goodfellow_2016}.

\subsubsection{Adaptive learning rates}
AdaGrad~\cite{duchi_2011} scales every coordinate by the
accumulated squared gradients,
\begin{align}
    \bm{r}^{(k)} &= \bm{r}^{(k-1)} + \bm{g}^{(k)}\odot\bm{g}^{(k)}, \\
    \bm{\theta}^{(k+1)} &= \bm{\theta}^{(k)} - \frac{\gamma}{\sqrt{\bm{r}^{(k)}}
    + \epsilon}\odot\bm{g}^{(k)},
\end{align}
where $\bm{g}^{(k)}$ is the gradient, $\odot$ the elementwise product, and the
square root and division are elementwise. The effective step of each coordinate
decreases monotonically. RMSprop replaces the sum by an exponentially decaying
average, $\bm{v}^{(k)} = \rho\bm{v}^{(k-1)} + (1-\rho)\,\bm{g}^{(k)}\odot
\bm{g}^{(k)}$, so the step size can recover~\cite{goodfellow_2016}.
Adam~\cite{kingma_2017} combines a decaying average of the
gradient (momentum) with RMSprop's scaling and corrects both for their
initialization at zero:
\begin{align}
    \bm{m}^{(k)} &= \beta_1\bm{m}^{(k-1)} + (1-\beta_1)\,\bm{g}^{(k)}, \\
    \bm{v}^{(k)} &= \beta_2\bm{v}^{(k-1)} + (1-\beta_2)\,\bm{g}^{(k)}\odot\bm{g}^{(k)}, \\
    \bm{\theta}^{(k+1)} &= \bm{\theta}^{(k)} - \gamma\,
    \frac{\bm{m}^{(k)}/(1-\beta_1^{k})}{\sqrt{\bm{v}^{(k)}/(1-\beta_2^{k})}+\epsilon}.
\end{align}
We use $\beta = 0.9$ for momentum, $\rho = 0.9$ for RMSprop, $\beta_1 = 0.9$,
$\beta_2=0.999$ for Adam, and $\epsilon=10^{-8}$. Because Adam divides by the
running root-mean-square gradient, its step does not shrink in proportion to the
gradient near the minimum; with a fixed $\gamma$ it can keep taking steps of
order $\gamma$ there.

\subsubsection{Stochastic gradient descent}
For a cost that is an average over the data, $C(\bm{\theta}) = \frac{1}{n}
\sum_i c_i(\bm{\theta})$, stochastic gradient descent (SGD) replaces the full
gradient by the average over a mini-batch $\mathcal{B}_k$ of $M$ points,
\begin{equation}
    \bm{g}^{(k)} = \frac{1}{M}\sum_{i\in\mathcal{B}_k}\nabla_{\bm{\theta}}
    c_i\big(\bm{\theta}^{(k)}\big),
\end{equation}
an unbiased estimate of the full gradient~\cite{goodfellow_2016}. We
shuffle the training set once per epoch and split it into $\lceil n_\text{tr}/M
\rceil$ mini-batches, so one epoch costs the same number of floating-point
operations as one full-batch step but makes $\lceil n_\text{tr}/M\rceil$
updates. The gradient noise does not vanish at the minimum, so with a fixed
learning rate the iterates fluctuate around it; a decaying learning rate,
here $\gamma_t = \gamma_0/(1+ \delta t)$ with $t$ the number of updates, damps
these fluctuations~\cite{hjorth-jensen_2026}. Any of the
update rules above can be applied to $\bm{g}^{(k)}$.

\subsubsection{Gradient descent for Lasso}
Since \cref{eq:lasso-theta-hat} is not differentiable at $\theta_j = 0$, its
gradient is not defined there. The \emph{subgradient method} replaces the
derivative of $|\theta_j|$ by an element of the subdifferential
$\partial|\theta_j|$, i.e.\ it uses
\begin{equation}\label{eq:lasso_subgradient}
    \bm{g}(\bm{\theta}) = \frac{2}{n}\bm{X}^\top(\bm{X}\bm{\theta}-\bm{y})
    + \lambda\operatorname{sign}(\bm{\theta}),
\end{equation}
with $\operatorname{sign}(0) = 0$ (the minimal-norm choice) and no penalty on the
intercept, in place of the gradient in any of the update rules above. Unlike GD
on a smooth cost, the subgradient method with a fixed step does not converge to
the minimizer, only to a neighborhood of it whose size is proportional to the
step: every nonzero coefficient receives a push of magnitude $\gamma\lambda$
towards zero in each step, so a coefficient whose optimal value is zero
oscillates around zero instead of reaching it. Exact zeros, the defining
property of the Lasso solution, therefore appear only by coincidence.

\subsubsection{Automatic differentiation}
Automatic differentiation (AD) computes derivatives of a function given as a
program by applying the chain rule to the sequence of elementary operations the
program executes~\cite{baydin_2018}. It is
neither symbolic differentiation, which manipulates expressions and can produce
exponentially large derivative expressions, nor numerical differentiation, whose
finite differences carry truncation and round-off errors: AD evaluates the
derivative exactly up to floating-point round-off, at a specific input. In
reverse mode, which JAX's \texttt{grad} uses for a scalar cost, the program is
run forward once while storing intermediate values, and derivatives are then
propagated backwards; the full gradient costs a small constant multiple of one
evaluation of the cost, independent of the number of
parameters~\cite{baydin_2018}. At a point where
the function is not differentiable, AD returns the derivative of whichever
branch the program takes; for $|\theta|$ at $\theta=0$, JAX returns $1$, which
is an element of $\partial|\theta| = [-1,1]$ and hence a valid subgradient,
although not the minimal-norm one ($0$).
