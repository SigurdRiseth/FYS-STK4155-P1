\begin{abstract}
Runge's function is the classic example of polynomial interpolation
on equispaced points diverging as the degree increases, which makes
it a demanding test of how model complexity should be selected. We
fitted polynomials of degree up to 15 to noisy samples of the
function using ordinary least squares (OLS), Ridge and Lasso
regression, and estimated the test error with the bootstrap and k-fold
cross-validation. For OLS, the test mean squared error was minimized
